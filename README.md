## 方針
- **電波なしで完結**（岳人の森で回線が落ちた反省）。記録は端末内（localStorage）、提出は CSV 書き出し
- 一度開けば Service Worker で端末に保存され、圏外でも再読み込みできる
- 配色は瀬戸内国際芸術祭、ボタンは YAMAP の DESIGN.md（awesome-design-md-jp）を参照

## 画面
| 区分 | 画面 | 中身 | 授業との対応 |
|---|---|---|---|
| A 波 | 波の周期タイマー | 波が目印を通るたびにタップ → 周期T・2π/T | 弧度法・周期 |
| A 波 | 波の上下トラッカー | 浮遊物の上下を指でなぞる → グラフ → y=A sin(2πt/T+φ)+C を手で重ねる（ぴったり度） | 三角関数のグラフ・変形（11/13〜） |
| A 波 | 回転と波 | 円を回る点の射影 → sin のグラフ。4πまで | 一般角・弧度法（11/4） |
| B 測量 | 高さを測る | 距離×tanθ＋目の高さ。±1°の誤差範囲、70°以上で警告 | 三角比（復習） |
| B 測量 | 近づけない高さ | 2地点の仰角 → 正弦定理 | 正弦定理（中間範囲） |
| B 測量 | 沖までの距離 | 基線AB＋両端の角度 → 正弦定理（三角測量）。方位センサーは目安 | 正弦定理（中間範囲） |
| ART | 波のアート | sin を最大3つ重ねて「しま模様」「波紋・貝」を生成 → PNG保存。トラッカーの波を取り込める | グラフの変形・重ね合わせ |
